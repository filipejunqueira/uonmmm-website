# Project Overview

## Project Purpose
This is a research group website for the "Molecules, Magnets & Materials" research group at the University of Nottingham. The website showcases:
- Research group activities and publications
- Staff members and their research focus
- Contact information and research areas
- Visual content about materials science, molecular research, and magnetic materials

## Tech Stack
- **Frontend Framework**: React 19.1.0
- **Build Tool**: Vite 6.3.5
- **Styling**: Tailwind CSS with custom configuration
- **Language**: JavaScript (JSX)
- **Deployment**: GitHub Pages (based on vite config base path)

## Project Structure
- `/src` - Main source code
  - `/components` - React components (Navbar, HeroSection, ContactSection, etc.)
  - `/assets` - Images, SVGs, and other static assets
  - `/data` - Publications and other data files
- `/public` - Static public assets (currently only favicon.svg)
- `/.github/workflows` - GitHub Actions deployment workflow
- Root config files for Vite, Tailwind, ESLint, PostCSS

## Key Features
- Responsive design with Tailwind CSS
- Dark mode support (class-based)
- Research publications display
- Staff member profiles
- Contact forms
- Multiple research sections (Materials, Molecules, Magnets)
- Hero section with group imagery
